# ♻️ RECYCLIQ

### Recycle Smarter. Create More.

RECYCLIQ is an AI-powered circular economy platform that transforms
waste into opportunities through intelligent identification,
upcycling recommendations, and recycling discovery.

## Core Features

- AI-powered waste identification
- Intelligent waste analysis
- AI-powered upcycling suggestions
- Recycling centre discovery
- Waste exchange marketplace
- Environmental impact tracking

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- Python
- FastAPI
- PostgreSQL
- Google Gemini API
- YOLO
- OpenCV

Currently under development.
